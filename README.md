# 🧳 Travel List

**Travel List** is a sleek, interactive React application designed to help users efficiently manage their packing items before a trip. Users can add items, mark them as packed or unpacked, remove them individually, or clear the entire list with a single click. The app also displays dynamic travel stats for better planning.

---

## 🚀 Features

- ➕ Add travel items with quantity  
- ✅ Mark items as packed or unpacked  
- 🗑️ Remove individual items  
- 🧹 Clear all items with confirmation  
- 📊 View live packing statistics  

---

## 🛠️ Tech Stack

- **React.js** (with Hooks: `useState`)  
- **JavaScript (ES6+)**  
- **CSS** for styling  

---

## 📂 Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/saileshmuvvala/travel-list.git
   ```

2. **Navigate to the project folder:**

   ```bash
   cd travel-list
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Start the development server:**

   ```bash
   npm run dev
   ```
